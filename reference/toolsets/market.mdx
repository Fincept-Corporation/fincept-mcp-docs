Toolset `market`: 15 tools. List them all with `?toolsets=market`, or let the agent find them with `fincept_search_tools`. Full descriptions and input schemas: `fincept_describe_tool`.

| Tool | What it does | Type |
| --- | --- | --- |
| `market_search_instruments` | Search the instrument universe by ticker, name or ISIN. | Read, core |
| `market_query_universe` | Every instrument matching a filter (country, exchanges, type, sector, market-cap band, index membership, metrics), 500 rows per page with `next_offset` for the rest. Use it for complete listings such as all NSE stocks. | Read, core |
| `market_get_quote` | Latest quote for one symbol: price, change, change percent, day range, volume, currency, exchange time and the feed's delay. | Read, core |
| `market_get_quotes` | Latest quotes for up to 300 symbols in one call. | Read, core |
| `market_get_candles` | OHLCV candles for a symbol, oldest first. Daily and coarser bars carry `date`, their trading day at the exchange; weekly, monthly and quarterly answers have one bar per period and say in `last_bar_partial` whether the last one is still running; `adjust: "splits"` gives price-only bars. | Read, core |
| `market_get_returns` | Returns of up to 100 symbols over up to 12 calendar periods in one call: a month, quarter, year or date range, each as the last close inside the period over the last close before it, in percent, on price (default) or total-return closes. Takes symbols as `scan_run` answers them. | Read |
| `market_get_snapshot` | An instrument's row in the symbol index: identity, listing, classification (type, sector, country, currency) and the index's stored metrics stamped with metrics_as_of. | Read |
| `market_get_fundamentals` | Key fundamentals for an equity: valuation ratios, margins, growth, balance-sheet figures, dividend and share data as the provider reports them. | Read, core |
| `market_get_profile` | Company profile: name, sector, industry, country, website, employees and business summary. | Read |
| `market_get_peers` | Comparable companies for a symbol from the classification index, most similar first. | Read |
| `market_get_options_chain` | The listed option chain for an underlying at its nearest expiry: calls and puts with strike, bid, ask, implied volatility and open interest. | Read |
| `market_get_corporate_actions` | Splits and dividends for a symbol between two dates (YYYY-MM-DD). | Read |
| `market_get_holidays` | Trading holidays and half days of one exchange calendar between two dates (default: the current calendar year). | Read |
| `market_get_futures_curve` | The term structure of a futures root (e.g. CL, ES, GC): each listed contract with expiry and last price, nearest first. | Read |
| `market_get_economic_calendar` | Upcoming macro releases and central-bank events in UTC, soonest first, deduplicated. | Read, core |

**Type:** Read tools only read. Write tools change your account; Delete tools remove something from it. `core` tools are listed by default. `credits` tools can spend credits; see [credits](/reference/toolsets/credits).
