| Tool | What it does | Notes |
| --- | --- | --- |
| `panel_system_regression` | Estimates a system of linear equations jointly: SUR (feasible GLS exploiting correlated errors, with optional cross-equation constraints), three-stage least squares or system GMM when equations have endogenous regressors. |  |
