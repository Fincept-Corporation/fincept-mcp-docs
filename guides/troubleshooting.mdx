---
title: "Troubleshooting"
description: "Fixes for common connection, sign-in and tool errors."
icon: "wrench"
---

<AccordionGroup>
  <Accordion title="The client says the server needs authentication">
    Run the client's sign-in: `/mcp` then **Authenticate** in Claude Code, `codex mcp login fincept` in Codex, the login action in Cursor or VS Code MCP settings.
  </Accordion>
  <Accordion title="The connect page says an active plan is required">
    The account you signed in with has no active Exclusive Pro plan. Check it at [fincept.in/enterprise/account](https://fincept.in/enterprise/account), or sign in with the account that has it.
  </Accordion>
  <Accordion title="Every call returns upgrade_required">
    Your plan changed or lapsed after you connected. Renew or upgrade, then retry; there is no need to sign in again.
  </Accordion>
  <Accordion title="Calls stopped working after a while">
    The connection was ended: a password change, a refresh token used twice, or more than 20 connections on the account. Sign in again from the client.
  </Accordion>
  <Accordion title="Codex asked me to sign in twice">
    `codex mcp add` signs you in already. Running `codex mcp login` straight after starts a second sign-in. Both work; Codex keeps the second.
  </Accordion>
  <Accordion title="PowerShell rejects && in a command">
    Windows PowerShell 5.1 does not support `&&`. Run each command on its own line, or use `;`.
  </Accordion>
  <Accordion title="The agent says a tool does not exist">
    Only the core set is listed. Ask the agent to use `fincept_search_tools`, or name the tool. A name the catalog does not have returns `unknown tool`.
  </Accordion>
  <Accordion title="A result says status partial">
    The result was too large to send whole. The agent reads the rest with `fincept_read_result`, or open `artifacts[0].view_url` in the browser. See [large results](/guides/results#large-results).
  </Accordion>
  <Accordion title="A stats tool returns validation_failed">
    The message names the argument at fault. Common causes: series of different lengths in one table, too few observations for the model, a formula naming a column the table lacks, or a `$fincept` path that does not exist in the referenced tool's data.
  </Accordion>
  <Accordion title="HTTP 429 Too Many Requests">
    The account passed 120 requests per minute. Clients back off and retry; agents that loop over many symbols should use batch tools such as `market_get_quotes`.
  </Accordion>
</AccordionGroup>

Error codes are listed in the [errors reference](/reference/errors).
